# CSELEC3C Course Project

## Data Visualization Project

This repository contains the files, datasets, and development work for our **Data Visualization Course Project**.

The project focuses on exploring energy access, renewable energy consumption, and economic development using data from the **World Bank World Development Indicators (WDI)**.

More updates and project outputs will be added as the project progresses.

## Datasets

The project uses the following indicators from the **World Bank World Development Indicators (WDI)**:

| Dataset Name | Indicator Code |
|---|---|
| Access to Electricity | `EG.ELC.ACCS.ZS` |
| Access to Clean Fuels and Technologies for Cooking | `EG.CFT.ACCS.ZS` |
| Renewable Energy Consumption | `EG.FEC.RNEW.ZS` |
| GDP per Capita | `NY.GDP.PCAP.KD` |

### Study Period

The analysis covers the period **2000–2022**, which represents the common coverage period used across the four selected indicators.
